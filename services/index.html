Web and software development services

I build websites, online stores, APIs, dashboards and automation as an independent web and software developer in Kenya. My name is John Mwaura, and I work as Dev John. The starting package and final quote depend on what the project needs to do.

Full-stack product development

I build the interface, database and backend as parts of one product. Authentication, data structure and deployment belong in the same discussion as the screens people use. A small internal application and a public platform can both need full-stack work, with very different scopes. The custom software guide explains how I separate a clearly bounded project from a larger product.

Read about full-stack product development

API architecture and systems integration

When two systems need to exchange information, an API defines how that exchange happens. I work on backend services, payment connections, webhooks and authentication flows. The starting point is the data that needs to move and the action that should follow. Provider access and the existing system need review before an integration can become part of the agreed scope.

E-commerce and payment platforms

An online store needs product information, a cart, checkout and a way for the business to handle orders. I build those parts together and work with M-Pesa Daraja and Stripe where appropriate. The starter package includes basic store administration. More detailed inventory rules, customer workflows or reporting need to be discussed against the actual store requirements.

Read about e-commerce and payment platforms

WhatsApp automation and customer workflows

A customer message can start a lead record, an order workflow or a notification to a business tool. I use the WhatsApp Cloud API to connect conversations with these actions. The useful question is what happens after the message arrives. Automation should have a defined task, the information it needs and a clear place for that information to go.

Read about whatsapp automation and customer workflows

Dashboards and internal operations systems

I build reporting interfaces and administrative tools for people running a business or platform. These can include role-based access, audit trails and operational records. Before choosing charts or screens, we need to know which decisions staff make and which records they need. The amount of custom reporting and access control affects whether the work fits a small project or an advanced platform.

Performance engineering and technical SEO

A page needs to load, respond to input and make its content understandable to search engines. My work includes Core Web Vitals checks, caching, structured data and technical SEO. Clear headings and readable page content matter alongside the code. Technical improvements remove obstacles to discovery, but they do not create a guarantee of search positions or business results.

Cloud deployment and DevOps

Getting software into production involves environments, deployment pipelines and the infrastructure around the application. My stack includes Docker, GitHub Actions, Linux and Nginx. The appropriate setup depends on the product and its requirements. Tell me about the existing hosting environment if there is one, so deployment work can be discussed with the rest of the project rather than assumed from a page price.

Public sector and civic-tech platforms

I build public-data and accountability interfaces, with UWAZI as my flagship example in Kenya. Civic technology can involve searchable records, case management and information presented for public use. The data model and the interface both matter. A project discussion needs to cover who supplies the records, how people will use them and which parts of the workflow need software.

Which one do I need?

Start with the action you want someone to take. If visitors need to learn about your business and send an enquiry, a business website may be enough. Selling products through a cart and checkout points towards an online store. A product showcase without checkout can fit a website package instead.

If staff are copying records between spreadsheets, or you need forms and reports tied to business rules, describe that workflow as a custom software enquiry. If most of the work starts in customer messages, explain the WhatsApp conversation and what should happen next. You do not need to choose the technology before contacting me.
